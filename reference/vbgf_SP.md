# Sex-aggregate von Bertalanffy growth parameters for Semelparous American shad

A dataset containing sex-aggregate estimates of von Bertalanffy growth
parameters for Semelparous life-history region. Data frame contains
posterior draws from coast-wide growth models (Gilligan 2019).

## Usage

``` r
vbgf_SP
```

## Format

A data frame with 1500 observations of 3 variables:

- `Linf`:

  Asymptotic length of fish

- `K`:

  Brody growth coefficient

- `t0`:

  Size at age zero

## Source

Gilligan, E. K. 2019. Understanding influences of climate change on
American Shad recovery, fisheries management, and dam impacts. Master's
Thesis, SUNY Oneonta, Oneonta, NY, USA.
