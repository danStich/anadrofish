# Sex-specific maximum ages of American shad

A dataset containing sex-specific maximum ages for each life-history
region (NI = Northern iteroparous, SI = Southern iteroparous, SP =
Semelparous).

## Usage

``` r
max_ages
```

## Format

A data frame with 6 observations of 3 variables:

- `region`:

  Life-history region

- `sex`:

  Fish sex

- `maxage`:

  Maximum observed age

## Source

Atlantic States Marine Fisheries Commission
