# Make output vectors

Internal function to create output vectors in
[`sim_pop`](https://danstich.github.io/anadrofish/reference/sim_pop.md).
Not intended to be called directly.

## Usage

``` r
make_output(nyears, sex_specific = FALSE)
```

## Arguments

- nyears:

  Number of years for simulation output.

- sex_specific:

  Logical inherited from
  [`sim_pop`](https://danstich.github.io/anadrofish/reference/sim_pop.md)
  indicating whether to use sex-specific output.
