# Sex-specific von Bertalanffy growth parameters for blueback herring

A dataset containing sex-specific estimates of von Bertalanffy growth
parameters for blueback herring from the 2024 ASMFC river herring
benchmark stock assessment (ASMFC 2024).

## Usage

``` r
vbgf_bbh
```

## Format

A data frame with 816,000 observations of 5 variables:

- `Region`:

  Genetic reporting group

- `Sex`:

  Sex of fish

- `linf`:

  Asymptotic length of fish

- `k`:

  Brody growth coefficient

- `t0`:

  Size at age zero
