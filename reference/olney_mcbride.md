# Weight-batch fecundity relationships for American Shad

A dataset containing weight-batch fecundity relationships for St. Johns,
York, and Connecticut Rivers from Olney and McBride (2003). Regressions
fit log10 batch fecundity as a function of log10 body weight (g).

## Usage

``` r
olney_mcbride
```

## Format

A data frame with 3 observations of 4 variables:

- `system`:

  Study system

- `region`:

  Life-history region: NI = Northern iteroparous, SI = Southern
  iteroparous, SP = Semelparous

- `alpha`:

  Intercept

- `beta`:

  Slope

## Source

Olney, J. E. and R. S. McBride. 2003. Intraspecific variation in batch
fecundity of American shad (\*Alosa sapidissima\*): revisiting the
paradigm of reciprocal latitudinal trends in reproductive traits.
American Fisheries Society Symposium 35:185-192.
