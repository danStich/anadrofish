# Fork length - total length conversions for river herring

A dataset containing species-specific fork length - total length
conversions from ASMFC (2024). The data are regression coefficients and
standard errors for each species.

## Usage

``` r
fl_tl_conversions
```

## Format

A data frame with 2 observations of 5 variables:

- `species`:

  Species of river herring ("ALE" or "BBH")

- `alpha`:

  Intercept

- `alpha.se`:

  Standard error of the intercept

- `beta`:

  Slope

- `beta.se`:

  Standard error of the slope

## Source

Atlantic States Marine Fisheries Commission
