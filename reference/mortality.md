# Sex-specific instantaneous mortality of American shad

A dataset containing sex-specific instantaneous mortality estimates for
each life-history region (NI = Northern iteroparous, SI = Southern
iteroparous, SP = Semelparous).

## Usage

``` r
mortality
```

## Format

A data frame with 6 observations of 3 variables:

- `region`:

  Life-history region

- `sex`:

  Fish sex

- `M`:

  Instantaneous natural mortality

## Source

Atlantic States Marine Fisheries Commission
